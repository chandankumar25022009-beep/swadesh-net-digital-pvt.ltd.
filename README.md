अगर तुम MongoDB वाला version चाहते हो:

1. **MongoDB Atlas** पर जाओ: https://mongodb.com/atlas
2. **Free account** बनाओ
3. **Connection string** को `app.js` में paste करो
4. Terminal में:
```bash
npm install
node app.js
```
5. Browser में: `http://localhost:3000`

## ❓ Troubleshooting:

### **Email not showing?**
- Make sure recipient username is correct
- Check if user exists in system

### **Chat not working?**
- Both users need to be registered
- Select user from chat list first

### **Data not saving?**
- Check browser localStorage is enabled
- Try clearing browser cache
